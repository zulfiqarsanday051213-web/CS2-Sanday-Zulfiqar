# Electricity Bill Calculator

## Description
This programs calculates the total electricity bill according to electricity consumption

## Version 1 - Original code without input validation
- Input: Accepts a person's name, previous meter reading, and current meter reading
- Process: Calculates and displays the electricity consumption and total bill.
- Output: Name, Electricity consumption, Total bill in PHP.
- Doesnt include input validation.

## Version 2 - Code with input validation
- Input: Accepts a person's name(must not be blank), previous meter reading(Number at least 0), and current meter reading(Number at least the previous reading)
- Process: Calculates and displays the electricity consumption and total bill.
- Output: Name, Electricity consumption, Total bill in PHP.
- Includes input validation.
